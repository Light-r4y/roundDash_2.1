# roundGauge — CAN-приборка на ESP32-S3

**Русский** | [English](README_en.md)

[![Platform](https://img.shields.io/badge/platform-ESP32--S3-blue)](https://www.espressif.com/en/products/socs/esp32-s3)
[![Framework](https://img.shields.io/badge/framework-ESP--IDF%20v6.0-red)](https://github.com/espressif/esp-idf)
[![GUI](https://img.shields.io/badge/GUI-LVGL%209-orange)](https://lvgl.io)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

Прошивка приборки для автомобиля на круглом сенсорном экране
[Waveshare ESP32-S3-Touch-LCD-2.1](https://www.waveshare.com/wiki/ESP32-S3-Touch-LCD-2.1)
(480×480): данные берутся из шины CAN, что и как показывать, настраивается
через веб-страницу по Wi-Fi, управление — две кнопки на разъёме платы и свайпы
по экрану.

> 🧪 **Состояние: рабочий прототип.** Экраны, редактор, загрузка картинок и точка
> доступа проверены на плате. **Приём CAN с реальной шины, обновление по воздуху
> (`/ota`), главная страница веба (яркость, пароль) и часть виджетов ещё не
> проверены на железе** — полный список в [docs/fw-design.md §11](docs/fw-design.md).

## 🔧 Железо

- **Плата** Waveshare ESP32-S3-Touch-LCD-2.1: ESP32-S3R8, 16 МБ флеш, 8 МБ PSRAM.
  Схема и даташиты — в [hw/](hw/README.md).
- **CAN-трансивер** 3.3 В (SN65HVD230 или TJA1051T/3) — на плате его нет.
- **Питание** в машине — DC-DC 12→5 В с защитой от бросков напряжения.

Всё подключается к разъёму J9 «12PIN Multi-function Interface»:

| Пин J9 | Сигнал | Назначение |
|---|---|---|
| 2 | 5V | питание от DC-DC |
| 1, 5, 11 | GND | |
| 6 | 3V3 | питание трансивера |
| 3 | GPIO19 | CAN RX |
| 4 | GPIO20 | CAN TX |
| 12 | GPIO0 | кнопка 1 (параллельно BOOT) |
| 10 | GPIO44 | кнопка 2 |

> ⚠️ В машине питайте плату через пин 2 J9, а не через Type-C: пока на Type-C
> есть питание, переключатель на плате отдаёт GPIO44 USB-UART, и кнопка 2 не
> работает. На столе по Type-C остаётся кнопка 1. Подробности —
> [docs/fw-design.md §3](docs/fw-design.md).

## 🚀 Быстрый старт

Проект ESP-IDF лежит в `fw/`, не в корне репозитория. В VS Code с расширением
Espressif откройте `roundGauge.code-workspace` (или папку `fw`), иначе кнопка
Build будет искать `CMakeLists.txt` в корне.

```bash
cd fw
idf.py build
idf.py -p COM5 flash monitor
```

Порт — тот, под которым определился USB-UART CH343 на Type-C платы; режим
прошивки включается сам. Цель (`esp32s3`), флеш 16 МБ, PSRAM и таблица разделов
уже заданы в `fw/sdkconfig.defaults`. Удалите `fw/sdkconfig` после правки
`sdkconfig.defaults`, иначе новые значения не подхватятся.

> 💡 **Windows:** если ESP-IDF ставился через EIM, а системный Python новее
> 3.11, `export.ps1` не найдёт своё окружение. Перед ним поставьте Python из
> состава IDF первым в `PATH`:
> ```powershell
> $env:PATH = "$env:USERPROFILE\.espressif\tools\idf-python\3.11.2;$env:PATH"; . $env:USERPROFILE\esp\v6.0\esp-idf\export.ps1
> ```

### Первый запуск

После прошивки на экране три встроенных экрана: RPM (циферблат), COOLANT (кольцо),
SPEED (число). Данных ещё нет, поэтому значения показывают `--`. Чтобы увидеть их
живыми, не подключая шину:

1. **Удерживайте кнопку 1 две секунды** — на экране появится карточка с именем сети
   (`roundGauge-XXXX`), паролем (`roundgauge`) и адресом.
2. Подключитесь к этой сети с телефона или ноутбука, откройте `http://192.168.4.1/`.
3. Раздел **CAN** → включите **«Демо»** → Применить. Значения побегут.
4. Раздел **Экраны** — настройка вида: перетаскивайте виджеты на предпросмотре,
   «Применить на приборке» отправляет раскладку на плату сразу.
5. Раздел **Медиа** — свои фоны, стрелки и шрифты.

### Управление

| Действие | Результат |
|---|---|
| Кнопка 1, короткое нажатие | следующий экран |
| Кнопка 1, удержание 2 с | точка доступа Wi-Fi |
| Кнопка 1, удержание 10 с | снять забытый пароль на настройки |
| Кнопка 2 | следующий экран |
| Свайп влево / вправо | следующий / предыдущий экран |

### Опции сборки

```bash
idf.py -D RG_HAS_TOUCH=0 build   # экран без тач-панели
```

Значение живёт в кэше сборки; вернуть тач — `idf.py -D RG_HAS_TOUCH=1 reconfigure`.
Строки FPS сверху экрана отключаются константой `RG_UI_SHOW_FPS` в
`fw/common/config/conf.h`. Подробнее — [docs/fw-design.md §10](docs/fw-design.md).

## 📦 Релизная сборка

```bash
tools/build/build.sh        # Linux/macOS
tools\build\build.bat       # Windows
```

Скрипт сам находит ESP-IDF, если окружение не активировано, ставит версию
`0.<ГГ>.<ММДД>` в `fw/version.txt`, собирает с уровнем логов WARN и складывает
в `releases/roundGauge_v<версия>_<время>/` полный комплект: прошивку, образы
`www` и `media`, загрузчик, таблицу разделов, `ota_data_initial.bin` и
`flash_args`. Новая плата прошивается из этой папки одной командой:

```bash
python -m esptool --chip esp32s3 -b 460800 --before default-reset --after hard-reset write-flash "@flash_args"
```

Прошивка заменяет раздел `media` базовым набором (загруженные через веб картинки
пропадают); раскладка экранов, таблица CAN, настройки и пароль лежат в NVS и
сохраняются.

## 🌐 Веб-интерфейс без железа

```bash
python tools/webtest/mock_server.py
```

Открыть `http://localhost:8088/`. Сервер раздаёт `fw/www` как есть и
имитирует API платы, включая CAN с поддельными кадрами — подробности в
[tools/webtest/README.md](tools/webtest/README.md).
