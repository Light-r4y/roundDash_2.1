# Ручное тестирование веб-интерфейса (без прошивки/железа)

Мок-сервер для проверки страниц из `fw/www` в обычном браузере на компьютере,
без ESP32 и без сборки прошивки.

## Запуск

```
python tools/webtest/mock_server.py
```

(или `python3`; по умолчанию порт 8088, другой порт — первым аргументом:
`python mock_server.py 8090`; `--password ПАРОЛЬ` включает защиту паролем)

Затем открыть в браузере:

- `http://localhost:8088/` — главная страница
- `http://localhost:8088/ota` — обновление прошивки и веб-интерфейса

## Что это делает

- Раздаёт статику напрямую из `fw/www` — тот же набор файлов, что попадёт в
  образ раздела www. Правки видны сразу после обновления страницы.
- Отдаёт `/ota` прямо из `fw/tasks/webcfg/ota_page.h` — проверяется настоящая
  страница из прошивки.
- Подменяет `/api/*` эндпоинты из `docs/fw-design.md` §6: `/api/status`,
  `/api/auth/status`, `/api/auth/verify`, `/api/ota/update`, `/api/www/update`.

## Ограничения

- Состояние хранится только в памяти процесса — перезапуск сервера сбрасывает
  его.
- Загрузка образов на `/ota` только имитируется, ничего не записывается.
  Сценарии сбоев включаются параметром в адресе эндпоинта: `?fail=1` — ошибка
  записи, `?hang=1` — оборванное соединение, `?stall=1` — ответ не приходит,
  `?same=1` — загружен тот же образ.
- Настроек приборки в вебе пока нет, мокать нечего.
